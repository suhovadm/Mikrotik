Маленькая шпаргалка по классовой адресации, т.е. по классам сетей.

Класс | Диапазон первого октета  | Маска по умолчанию | Префикс | Назначение
------+--------------------------+---------------------+---------+----------------
A     | 1–126                    | 255.0.0.0          | /8      | Сети
B     | 128–191                  | 255.255.0.0        | /16     | Сети
C     | 192–223                  | 255.255.255.0      | /24     | Сети
D     | 224–239                  | Нет                | —       | Multicast
E     | 240–255                  | Нет                | —       | Зарезервирован

Коротко для запоминания:
A = /8  = 255.0.0.0
B = /16 = 255.255.0.0
C = /24 = 255.255.255.0
D = нет маски по умолчанию (Multicast)
E = нет маски по умолчанию (зарезервирован)

Классовая адресация сейчас практически не используется для маршрутизации, сейчас используется CIDR: /8, /16, /24, /30, /31 и т. д.
