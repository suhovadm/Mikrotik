Как выключить uPnP в Микротик и проверить не насоздавал ли он бэкдоров ?  

1)  

Через Winbox:  

IP - UPnP - Снимаем галочку с Enable, Apply - OK  
_________________________________________________________________________________________  

2)   

Через терминал ещё проще:  

/ip upnp set enabled=no  

И проверяем:  

/ip upnp print  
_____________________________________________________________________________________________  

3)   

Также, проверяем есть ли upnp-настройки интерфейсов.  
Это нужно, чтобы убедиться, что upnp ничего не открыл в Микротик.  

/ip upnp interfaces print  

Если там есть интерфейсы, их можно удалить.  
 
/ip upnp interfaces remove [find]  
_____________________________________________________________________________________________  

4)   

Теперь проверим NAT-правила.  
upnp может создавать динамические NAT-правила.  
Здесь важно обратить внимание на правила с флагом D (dynamic) и комментарии вроде upnp.  
Также, важно обратить внимание на вещи вроде dst-port=такой-то... Это проброс портов извне.  

/ip firewall nat print  

Можно также отдельно посмотреть динамические правила.  
Удалять их вслепую не надо, среди них могут быть правила, необходимые самому RouterOS.  

/ip firewall nat print where dynamic=yes  

_____________________________________________________________________________________________  

5)   

Уже открытые соединения после отключения UPnP могут ещё существовать до истечения таймаута.  
Посмотреть их можно командой:  

/ip firewall connection print  
_____________________________________________________________________________________________    

6)   

Если нужно закрыть доступ из интернета, проверяем dts-nat-правила:  

/ip firewall nat print where chain=dstnat  
_____________________________________________________________________________________________
